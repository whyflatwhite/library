# API

Базовый URL (локально): `http://localhost:8000`
Интерактивная документация (Swagger UI): `http://localhost:8000/docs`
Клиент: `http://localhost:8000/static/index.html`

## Авторизация

| Метод | Путь            | Тело запроса                              |
|-------|-----------------|---------------------------------------------|
| POST  | `/auth/register`| `{"username","password"}`                  |
| POST  | `/auth/login`   | `{"username","password"}` -> возвращает `access_token` |
| GET   | `/auth/me`      | заголовок `Authorization: Bearer <token>`  |

## Служебные

| Метод | Путь      | Описание                        |
|-------|-----------|----------------------------------|
| GET   | `/`       | Информация о сервисе              |
| GET   | `/health` | Проверка работоспособности + БД   |

## Авторы

## Книги

| Метод | Путь              | Тело / параметры                                                            |
|-------|-------------------|-------------------------------------------------------------------------------|
| POST  | `/books`          | `{"title","author_id","faculty_id"?,"isbn"?,"published_year"?}`             |
| GET   | `/books`          | query: `faculty_id` (опционально)                                            |
| GET   | `/books/{id}`     | -                                                                              |

Ошибки: 400 - автор/факультет не найден; 422 - некорректные данные (например, `published_year` вне диапазона 1450–2100).

## Экземпляры

| Метод | Путь          | Тело / параметры                                     |
|-------|---------------|---------------------------------------------------------|
| POST  | `/copies`     | `{"inventory_number","book_id","branch_id"}`           |
| GET   | `/copies`     | query: `branch_id`, `book_id` (опционально)             |

## Выдачи (Loans)

| Метод | Путь                    | Тело / описание                                                    |
|-------|-------------------------|------------------------------------------------------------------------|
| POST  | `/loans`                | `{"copy_id","borrower_name"}` - выдать экземпляр                       |
| POST  | `/loans/{id}/return`    | - оформить возврат                                                     |
| GET   | `/loans`                | query: `active_only=true` - только активные (невозвращенные) выдачи   |

Правило: `POST /loans` вернет `400`, если экземпляр уже выдан и не возвращен.

## Отчеты

| Метод | Путь                          | Описание                                             |
|-------|-------------------------------|---------------------------------------------------------|
| GET   | `/reports/popular-books`      | Топ книг по числу выдач (query: `limit`, по умолчанию 10)|
| GET   | `/reports/copies-by-branch`   | Кол-во экземпляров и сколько выдано, по филиалам        |
