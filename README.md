# Library API - учет книг, авторов, филиалов, экземпляров и их использования

Минимально работоспособное приложение для университетской библиотеки:
HTTP API + реляционная БД (PostgreSQL), с полным Git/CI/CD-процессом.

## Предметная область

**Назначение**: учет книжного фонда университета - какие книги есть, у каких
авторов, в каких филиалах библиотеки, сколько экземпляров, кто и когда их брал.

**Категории пользователей**:
- Библиотекарь - регистрируется и входит в систему (логин/пароль), заводит книги, авторов, филиалы, экземпляры; выдает и принимает возврат.
- Читатель - фигурирует как имя в записи о выдаче, отдельного аккаунта не имеет.
- Администратор/деканат - смотрит отчеты (популярные книги, загрузка филиалов).

**Основные сценарии**:
1. Библиотекарь заводит автора, книгу, привязывает к факультету.
2. Библиотекарь регистрирует экземпляр книги в конкретном филиале.
3. Библиотекарь выдает экземпляр читателю (`POST /loans`).
4. Библиотекарь принимает возврат (`POST /loans/{id}/return`).
5. Администратор смотрит отчеты (`/reports/*`).

**Обязательное правило предметной области**: экземпляр нельзя выдать повторно,
пока не оформлен возврат предыдущей выдачи (см. `docs/DATA_MODEL.md`).

Сущности и связи - подробно в [`docs/DATA_MODEL.md`](docs/DATA_MODEL.md).
Описание API - в [`docs/API.md`](docs/API.md).
Правила внесения изменений - в [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md).

## Технологический стек

- Python 3.12, FastAPI, SQLAlchemy 2.0, Alembic (миграции), PostgreSQL 16
- pytest (тесты на изолированной SQLite in-memory БД)
- black/isort/flake8/mypy (качество кода)
- Docker + docker-compose (контейнерное окружение)
- GitHub Actions (CI: линт, тесты, сборка образа, проверка миграций)
Дополнено Ирой: используется PostgreSQL как основная база данных.

## Быстрый старт (без Docker)

Требуется установленный локально PostgreSQL.

```bash
cp .env.example .env
make setup
source .venv/bin/activate
make migrate
make run
curl http://localhost:8000/health
```

Swagger UI: http://localhost:8000/docs
Клиент: http://localhost:8000/static/index.html

## Запуск через Docker

```bash
make up
make migrate
curl http://localhost:8000/health
make down
```

## Структура репозитория

```
app/                  - исходный код приложения (FastAPI)
  routers/            - HTTP-эндпоинты по сущностям
  models.py           - ORM-модели (SQLAlchemy)
  schemas.py          - валидация запросов/ответов (Pydantic)
  crud.py             - работа с БД + бизнес-правила
migrations/           - миграции Alembic
tests/                - автотесты (pytest)
docs/                 - техническая документация проекта
.github/workflows/    - CI-конвейер
Makefile              - единый интерфейс команд проекта
docker-compose.yml    - Postgres + API в контейнерах
```
